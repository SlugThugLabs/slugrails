## 1. Community Edition (Free)

The Community Edition is free for all developers and organizations to use internally to analyze, audit, test, and maintain their own applications—including commercial software.

- **Cost:** Free
- **Includes:** Full local CLI, stdio MCP server for Cursor / Claude / Antigravity, local `.planning/ARCHITECTURE.md` contracts, built-in guards, and Git pre-commit hooks.
- **Permitted Use:** Any developer or internal team can use it freely to build and ship proprietary software.

---

## 2. Enterprise Fleet Governance (Commercial)

Designed for engineering leaders who need to enforce consistent architecture across dozens or hundreds of repositories touched by human developers and autonomous AI coding agents.

### Key Capabilities:
- **Centralized Guard Hub:** Define company-wide architectural rules once and sync them across all repositories automatically.
- **Managed GitHub / GitLab PR Gatekeeper:** Automatically audits incoming pull requests, blocks merges that introduce architectural drift, and comments actionable fixes directly for AI agents.
- **Drift Analytics & Metrics:** Executive visibility into codebase complexity, AI bloat rates, and exception lifecycles.
- **Audited Exception Workflows:** Central approval flow when developers or agents request exemptions to architectural rules.
